Compact mode and ghost text

Question this prototype answers: when should the result list open and close, and when should the dimmed completion (ghost text) appear and be accepted? Click the walkthrough tabs first, then free-play with the buttons. The candidate rules are written out below so you can point at the one that feels wrong.

Candidate rules under test

  • Open: the list is visible when compact is off, or the mode is clipboard, or the query is not empty.
  • R3: ghost text appears only when the top result's title literally starts with the query. Fuzzy matches with gaps get no ghost.
  • R4: ghost text is display-only until accepted with a dedicated action. Tab is already the mode switch, so it cannot also accept the ghost.
